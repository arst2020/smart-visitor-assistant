# Smart Visitor Assistant – دستیار هوشمند بازدیدکننده

افزونه‌ی وردپرس که بعد از نصب، سایت را خودش بررسی و تحلیل می‌کند و مثل یک دستیار هوشمند به بازدیدکننده‌ها کمک می‌کند.

- **سایت پزشکی:** خدمات را معرفی می‌کند و برای نوبت‌گیری به بخش نوبت‌دهی ارجاع می‌دهد.
- **فروشگاه (ووکامرس):** محصولات را پیدا می‌کند و کارت محصول نشان می‌دهد؛ اگر قیمت در سایت مخفی باشد، قیمت را هم نمایش نمی‌دهد.
- نوع سایت، صفحه‌های کلیدی (نوبت‌دهی، تماس، خدمات، سبد خرید و …) و اطلاعات تماس را خودکار تشخیص می‌دهد.
- دو حالت: **محلی** (رایگان، بدون API) و **هوش مصنوعی** (Claude یا هر API سازگار با OpenAI).
- فارسی، انگلیسی و آلمانی.

## نصب

آخرین نسخه را از [Releases](../../releases/latest) دانلود کنید (`smart-visitor-assistant.zip`) و از پیشخوان وردپرس: **افزونه‌ها ← افزودن ← بارگذاری افزونه** نصب کنید.

## به‌روزرسانی

افزونه نسخه‌های جدید را خودش از Releases همین مخزن پیدا می‌کند؛ در وردپرس پیام «به‌روزرسانی موجود است» می‌آید و با یک کلیک (یا به‌صورت خودکار) به‌روز می‌شود. منوی «دستیار هوشمند ← به‌روزرسانی» وضعیت را نشان می‌دهد.

## انتشار نسخه جدید (برای توسعه‌دهنده)

1. `Version:` و `SVA_VERSION` را در `smart-visitor-assistant.php` افزایش دهید.
2. به شاخه‌ی `main` push کنید.
3. GitHub Actions خودش zip قابل نصب را می‌سازد و ریلیز `vX.Y.Z` را منتشر می‌کند.
